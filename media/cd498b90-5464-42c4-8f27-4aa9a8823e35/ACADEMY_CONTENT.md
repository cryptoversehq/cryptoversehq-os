# CryptoVerse AI — Academy Content (for Academy Mentor Agent)

## Academy Structure
The Academy has **8 Modules** with **4 Lessons each** = **32 Total Lessons**.

## Modules & Lessons

### Module 1: Blockchain Basics
- Lesson 1: What is Blockchain? (distributed ledger, consensus, immutability)
- Lesson 2: How Cryptocurrencies Work (keys, addresses, transactions, mining/staking)
- Lesson 3: Wallets & Security (hot/cold wallets, seed phrases, private keys)
- Lesson 4: Introduction to Trading (exchanges, order books, basic terminology)

### Module 2: Market Analysis
- Lesson 1: Technical Analysis Fundamentals (candlesticks, trends, support/resistance)
- Lesson 2: Key Indicators (RSI, MACD, Moving Averages, Bollinger Bands)
- Lesson 3: Chart Patterns (head & shoulders, double top/bottom, triangles)
- Lesson 4: Volume Analysis (volume profile, OBV, accumulation/distribution)

### Module 3: Risk Management
- Lesson 1: Position Sizing (Kelly criterion, fixed fractional, risk per trade)
- Lesson 2: Stop Loss Strategies (percentage-based, ATR-based, trailing stops)
- Lesson 3: Portfolio Diversification (correlation, asset allocation, rebalancing)
- Lesson 4: Psychology of Trading (emotional discipline, FOMO, revenge trading)

### Module 4: DeFi & Advanced Trading
- Lesson 1: Decentralized Finance Basics (DEXs, liquidity pools, AMMs)
- Lesson 2: Yield Farming & Staking (APR/APY, impermanent loss, protocols)
- Lesson 3: Advanced Order Types (OCO, trailing stop-limit, iceberg orders)
- Lesson 4: Derivatives Trading (futures, options, perpetual swaps basics)

### Module 5: On-Chain Analysis
- Lesson 1: Reading Blockchain Explorers (Etherscan, BscScan, Solscan)
- Lesson 2: Whale Tracking (large transactions, wallet clustering, alerts)
- Lesson 3: Exchange Flows (inflow/outflow analysis, supply on exchanges)
- Lesson 4: Smart Money Analysis (profitable wallet tracking, copy strategies)

### Module 6: NFT Fundamentals
- Lesson 1: What are NFTs? (ERC-721/1155, ownership, metadata)
- Lesson 2: NFT Marketplaces (OpenSea, Blur, Magic Eden, Rarible)
- Lesson 3: NFT Valuation (rarity, utility, community, artist reputation)
- Lesson 4: NFT Trading Strategies (floor sweeping, sniping, trait-based)

### Module 7: Sentiment Trading
- Lesson 1: Fear & Greed Index (components, interpretation, extremes)
- Lesson 2: Social Media Analysis (Twitter/X trends, Reddit sentiment, influencers)
- Lesson 3: News Impact Analysis (regulatory news, adoption, partnerships)
- Lesson 4: Contrarian Trading (fading the crowd, capitulation signals)

### Module 8: Automated Trading
- Lesson 1: Introduction to Trading Bots (grid, DCA, arbitrage)
- Lesson 2: Bot Configuration (parameters, risk limits, scheduling)
- Lesson 3: Backtesting Strategies (historical data, performance metrics)
- Lesson 4: Bot Risk Management (max drawdown, stop conditions, monitoring)

## Quiz System
- Each lesson has a **4-question quiz**
- Pass threshold: **80% or higher** (must get at least 3 of 4 correct)
- Quizzes test comprehension of lesson material
- Failed quizzes can be retaken after reviewing the lesson

## XP System
- Earn XP by completing lessons and passing quizzes
- Earn XP from successful trades
- XP is awarded idempotently (once per lesson — no double-counting)

## User Level Progression
| Level Range | Title | XP Required | Features Unlocked |
|-------------|-------|-------------|-------------------|
| 1-4 | Novice | 0-399 XP | Basic trading, Academy Modules 1-2 |
| 5-9 | Apprentice | 400-999 XP | Copy trading, Academy Modules 3-4 |
| 10-14 | Analyst | 1000-1999 XP | Strategy Marketplace, Academy Modules 5-6 |
| 15-19 | Pro Trader | 2000-3999 XP | Bots, Academy Modules 7-8 |
| 20+ | Elite | 4000+ XP | All features, Real Exchange Connection |

Note: New users start with 1,250 XP and lessons 'l1' and 'l4' pre-completed, giving access to the first two modules by default.

## Teaching Approach for Academy Mentor
- Use simple language for Novice levels (Levels 1-4)
- Use technical depth for Pro Trader levels (Levels 15+)
- Create practice quiz questions on demand
- Track user progress and suggest next lessons
- Explain how XP is earned (lessons + successful trades)
- Guide users to features unlocked at each level tier
- Be patient and encouraging — celebrate learning milestones
- If user asks about live trading, redirect to Trading Mentor

## Common Academy Issues
- Quiz failed → review the lesson material and retry
- Can't access module → check if level requirement is met
- Progress not saved → complete full lesson (content + quiz)
- XP not updating → allow store sync (refresh if needed)
